# Checklist do Dia — Da IA aos Agentes

> Execute isso **30 minutos antes** de apresentar.

---

## Técnico

- [ ] `npm run dev` rodando → http://localhost:3002
- [ ] Slide 1 (Capa) na tela
- [ ] Zoom do browser em 100%
- [ ] Tela cheia (F11 ou ⌘+Shift+F)

## Kiro / Demo ao vivo

- [ ] Kiro aberto com o `seller-greenn-back`
- [ ] Verificar aba "Agent Hooks" — os 15 hooks aparecem?
- [ ] Abrir `.kiro/steering/` no Explorer — mostrar os arquivos
- [ ] Ter uma task VSUS recente em mãos pra demo do `jira-close-task`
- [ ] MCP Jira conectado (testar: perguntar "qual minha task mais recente no VSUS")

## Ambiente

- [ ] Slack/Teams: silenciar notificações
- [ ] Fechar abas desnecessárias
- [ ] Segunda tela configurada se for projetar

## Mental

- [ ] Revisar o [Guia de Apresentação](GUIA-APRESENTACAO.md) — especialmente os slides 8, 9, 10
- [ ] Lembrar: o objetivo é que o time entenda, não que você impressione
- [ ] Perguntas são bem-vindas a qualquer momento

---

## Durante a apresentação

**Se o Kiro travar:** não entre em pânico. Continue nos slides. Volte pra demo no final.

**Se alguém perguntar sobre um modelo específico:** "O Claude Sonnet 4.6 é o padrão hoje. O Kiro permite trocar o modelo nas configurações."

**Se alguém perguntar sobre custo:** "O Kiro tem plano gratuito individual e plano Enterprise para times. A Cogna/Voomp tem acesso corporativo."

**Se alguém quiser criar um Steering na hora:** deixa! É o melhor sinal que a apresentação funcionou.
