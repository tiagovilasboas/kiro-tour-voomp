**Empresa:** Dextra (consultoria para Globo)
**Período:** jan 2019 – fev 2021 (2 anos 2 meses)
**Papel:** Desenvolvedor Sênior

**Contexto:** Globo precisava de aplicações de streaming para Smart TVs — LG WebOS e Samsung Tizen — com foco em performance e compatibilidade entre plataformas distintas.

**O que fiz:**

**Impacto:**
- Uma base de código → múltiplos players

- Referência de padrão de desenvolvimento para plataformas OTT na Globo

**Tecnologias:** JavaScript, React, WebOS SDK, Tizen SDK, HTML5 Video API

## Slide 9 — Cogna / Voomp — Staff Engineer (hoje)

**Empresa:** Cogna Educação / Voomp Creators
**Papel:** Staff Engineer — Squad Sustentação N3

**Contexto:** Voomp Creators é plataforma de infoprodutos (edtech + fintech). Squad N3 = última linha de defesa técnica. PHP 7.4 / Lumen / MySQL / Redis / AKS.

**Cases reais (evidenciados pelo Jira + Azure DevOps):**

**VSUS-679 — Vendas duplicadas no checkout (Em produção)**
- Bug de alto impacto financeiro: compras gerando duas vendas no admin do Seller
- Análise completa do middleware de idempotência
- Fix: janela 60s + chave secundária por email+produto+valor
- 10 testes unitários — PR #148631 mergeado e em produção

**VSUS-701 — Push notifications offline 30 dias**
- ~4.300 sellers sem notificações push silenciosamente
- Investigação: Loki + banco + pipeline + git log
- Causa raiz: OneSignal deprecated endpoint sem aviso, faltava Authorization header
- Fix: novo header + Log::error + fallback gracioso + dashboard Grafana para push
- PR #149593 com 5 testes unitários
- Proposta proativa: alertas Datadog para evitar recorrência (VSUS-730)
- Proposta proativa: migração para novo endpoint OneSignal (VSUS-725)

**VSUS-709 — Export charges falhando silenciosamente**
- Jobs de exportação com FAILED sem feedback para o seller
- Mapeou fluxo completo: SaleController → FutureSalesProjection
- Causa raiz: `Carbon::parse(NULL)` em subscriptions de boleto sem paid_at
- Evidências confirmadas no banco DEV com queries SQL específicas

**Kiro DX — elevação do time inteiro:**
- 7 steerings, 2 skills, 2 hooks, 7 prompts — playbook público no GitHub
- Documentação no Confluence: Onboarding N3, Playbook Grafana, Post-Mortem, Agent Hooks
- Apresentação "Kiro com Intenção" — 15 slides para capacitar o time

**Tecnologias:** PHP 7.4, Lumen, MySQL, Redis, Loki, Grafana, Sentry, Kiro, Azure DevOps, AKS
