# Contributing

English for this file and pull requests.

This repo is a 17-slide onboarding deck (`src/slides/`), not a product. Do not invent new slides.

## Start

```bash
npm install
npm run dev
```

Open http://localhost:3002, or the live deploy linked from the README.

## Changes

- Deck copy: edit the existing slide file. Talk owner reviews wording.
- Docs: `docs/` is presenter support (script, checklist, hands-on). Same rule — no new slides from a drive-by PR.
- README: keep the opening as one-liner + Start. Keep the live Vercel link.

PRs: what / why / risk. MIT — see [LICENSE](LICENSE).
